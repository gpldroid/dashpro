# DashPro

A full-stack visual website builder and Blogger XML template generator.

## Stack

- Next.js App Router + TypeScript
- Tailwind CSS v4
- Supabase Auth, PostgreSQL, and Storage

## Getting started

1. Install Node.js 22 LTS or newer.
2. Install dependencies with `npm install`.
3. Copy `.env.example` to `.env.local` and add your Supabase publishable key.
4. Start the development server with `npm run dev`.

See the project setup guide in this README as the implementation progresses.
